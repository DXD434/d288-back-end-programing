# Checkout Workflow & Database Integration

This project demonstrates a complete checkout workflow built with Spring Boot, focusing on real-world backend design and data persistence.

# Cart Summary & Pricing Logic

The application displays a finalized cart view that includes:

Customer contact and address information

Selected vacation package and excursions

Automatically calculated total cost

Checkout action to submit the purchase

This confirms proper handling of user input, pricing calculations, and request preparation for backend processing.

Persistent Storage & Data Integrity

After checkout, the purchase data is successfully persisted to the database. This validates:

Customer creation and storage

Cart and cart item relationships

Vacation and excursion associations

Accurate storage of the final purchase total

The implementation demonstrates clean separation of concerns using controllers, services, and repositories, along with transactional data handling.

# Key Takeaways

End-to-end checkout flow implementation

RESTful API design with Spring Boot

Service-layer business logic

JPA entity relationships and database persistence

Realistic e-commerce domain modeling
